ЛР №1, вариант 29 — Кулинарные рецепты

Запуск: python main.py
Требуется Python 3.9 или новее. Внешние библиотеки не используются.

Файлы:
- main.py — классы, меню, CRUD, обработка исключений и работа с XML/JSON.
- class_diagram.puml — диаграмма классов PlantUML.

Программа позволяет добавлять, просматривать, искать, изменять и удалять рецепты,
а также сохранять и загружать коллекцию в форматах XML и JSON.
